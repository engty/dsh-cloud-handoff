## 待人工验证（真实桌面 GUI 安装后）

1. 输入区出现「☁ 转为云端运行」按钮；点击 → 输入任务说明 → 确认 → 状态变「云端执行中」。
2. 迁移期间本机合盖/关机，云端不受影响（cloud 在 PVE 常驻）。
3. 重开桌面 App 后 60 秒内自动同步，设置页显示「已同步」+ 摘要。
4. 失败路径：云端任务失败/中止 → 本机错误摘要自动展开。
5. 冲突路径：云端执行期间本机改动同一文件 → 回拉保留 `.cloud-*` 副本，不覆盖。
